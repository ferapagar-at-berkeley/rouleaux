## Cluster Labeling App

I want to build a simple html app that allows me to label clusters of red blood cells in images. 

Features: 
 - Images selector: allows selecting one or more images to label. Each image should in principle be an image generated by the extract_clusters function that utilizes the RBClusters image processor.
 - Labeler: A section that shows an specific cluster image and allows me to label the corresponding cells.
    - Show the image in a canvas, and below it, have a textbox where I will enter a sequence of numbers separated by spaces and/or commas. 
        - The amount of numbers represents the ground truth of the actual number of clusters present in the image. 
        - The numbers themselves tell exactly how many cells compose each cluster. 
        - For example, if the user enters "1,1,3,3", it means there are 4 clusters in the image. The first two clusters have 1 cell each, and the last two clusters have 3 cells each.
    - Pressing enter will move me to the next image. If the image was already labeled, the app should show the ground truth I previously entered for that image, so I can correct it if needed. 
- Additionally, there will be some navigation buttons: 
    - Previous image: go to the previous image. 
    - Next image: go to the next image. 
    - Searchable dropdown menu of all images, allowing me to jump to any image directly.
- The labels will be stored as a json object, where each key is the image name and the value is the label string (e.g. "1,1,3,3"). There will be a load button to load a previously saved json object and save button to save the current labels.
